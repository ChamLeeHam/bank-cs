## 如何提交人工客服工单 / Submitting a support ticket
可在客服对话中说明遇到的问题，并明确提出「转人工」或「帮我开工单」。简要说明发生时间、事项以及希望核查的内容。涉及一笔账单交易时，也可在「账单与交易」完成验证、打开交易详情，然后申请核查。提交后请保留工单编号。不要把密码、PIN、CVV 或验证码写进描述。

Describe what happened and ask for a human agent or a support ticket. Include the approximate time and what you want reviewed. For a specific statement transaction, complete verification, open the transaction detail and request a review. Keep the ticket number and omit credentials or codes.

## 如何查看工单进度和坐席回复 / Viewing ticket status and agent replies
在客户页面右上角选择「我的工单」，按提示完成演示身份验证后打开对应工单。详情可查看状态、进展和坐席回复。待处理表示尚未开始处理，处理中表示坐席已开始，已回复时可以查看回复内容，已关闭表示本次工单已结束。退款、交易撤销和卡片冻结的实际结果请分别核对对应记录。

Open “My tickets,” complete demo verification if prompted, and select the ticket. Pending means it is waiting for handling, in progress means an agent has started, replied means a response is available, and closed means the ticket is finished. Confirm any refund, reversal or freeze separately in the appropriate record.

## 工单已提交但还没解决怎么办 / Following up on an existing ticket
若已有相同问题的工单，先打开「我的工单」查看编号、最新回复和状态。需要补充信息或仍有疑问时，联系坐席并提供原工单编号与新增情况，避免重复提交同一问题。如果工单已经关闭但问题仍存在，请说明原工单编号和目前情况，让坐席核查后续处理方式。演示资料未规定对客户承诺的结案时间。

Check the latest status and replies before making a duplicate request. If you have new information or the issue persists after closure, contact an agent with the original ticket number and explain what still needs attention. The demo does not promise a resolution deadline.
